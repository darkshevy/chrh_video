# Идеи на будущее (когда софт станет солидным)

Монтаж:
1. Тизер результата в начале: 1–1,5 с лучшего кадра готовой работы, потом история с начала.
2. «До / после» в финале: экран пополам — кадр начала и готовый вид с похожего ракурса.
3. Последний кадр результата длиннее (3–3,5 с) с плавным наездом.
4. Плашки этапов: BEFORE / WELDING / DONE — понятно без звука.

Экономия:
5. Кэш озвучки ElevenLabs по тексту: тот же текст — тот же голос бесплатно.
6. Кэш отрендеренных кадров: после замены перерисовывается только изменённый кадр.
7. Переключатель «Проверить готовый ролик» (ревью Gemini) — выключать, когда спешишь.
8. Очередь проектов: отметить несколько и «Собрать все».
9. В сетке превью помечать клипы, где всё трясётся, до монтажа.
